# Choricar

Sitio estático del proyecto Choricar.

## Scripts

| Command | Description |
| --- | --- |
| `npm run deploy` | Publica `public/` en GitHub Pages |
| `npm run tailwind` | Compila Tailwind a `public/tailwind-dist.css` |
| `npm run tailwind:watch` | Compila Tailwind en modo watch |

## Deploy

`npm run deploy` publica el contenido de `public/` en la rama `gh-pages` del repo [kikeestradadev/choricar](https://github.com/kikeestradadev/choricar).

**GitHub Pages:** [https://kikeestradadev.github.io/choricar/](https://kikeestradadev.github.io/choricar/)
